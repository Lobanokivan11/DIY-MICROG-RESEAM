# DIY-MICROG-RESEAM

## NOTE!!!

Reseam Gmscore also being supported by [JingMatrix/LSPatch](https://github.com/JingMatrix/LSPatch) since [canary-490](https://github.com/JingMatrix/LSPatch/releases/tag/canary-490) version

In case of errors on LSPatch install and activate this module from [link](https://github.com/Lobanokivan11/DIY-MICROG-RESEAM/raw/refs/heads/main/MG-XPOSED.apk)

## How to Install (Universal)

1. Download And install ```gmscore-user.apk```

2. Open Reseam Gmscore Settings(MicroG Settings) Enter Self-check page And Grant All Permission Excluding Spoof Signature Permission (This Not Required).

3. Enter Google Accounts and login into Google Account as always

4. That's All, Install Youtube Reseam or anything Youtube With Other Reseam patches you want Open it and gongratulations You may watch Any Videos From Youtube.
